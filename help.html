必要環境 / Requirements

  • Windows and Python 3.10 or later with Tkinter / Windows、Python 3.10以降（Tkinterを有効化）
  • No additional pip packages are required / pipでの追加インストールは不要
  • Node.js is not included; install it and add it to PATH only for JavaScript plugins (.js and .ssp) / Node.jsは同梱されず、JavaScriptプラグイン（.js、.ssp）を使う場合のみ別途インストールしてPATHを通します

Extract the ZIP and run py SWS_GUI.py. This is Python source, not a standalone EXE installer. / ZIPを展開して py SWS_GUI.py で起動します。単体実行できるEXEではありません。
