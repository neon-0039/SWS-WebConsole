SWS Data Plugins

SWS Plugin API

A data plugin is a JavaScript file whose body receives the compiled song object as SWS. Load it here, then call plugin("fileName") in your SWS source.

Data object fields: api_version (currently 1), sws_version, type ("song"), project, and events. Project contains tempo, key, and tempo_map. Each event contains its type, instrument, start, duration, notes, class, volume, lyric, and source position. 

if (SWS.api_version !== 1) {
  throw new Error("Unsupported SWS API");
}
console.log(SWS.project.tempo);
console.log(SWS.events.length);

Output plugins use a separate API. Their file must return an object with render(song, sampleRate). It must return an object whose left and right fields are equal-length, non-empty Float32Array audio channels. 

return {
  render(song, sampleRate) {
    const leftChannel = new Float32Array(1);
    const rightChannel = new Float32Array(1);
    return { left: leftChannel, right: rightChannel };
  }
};
