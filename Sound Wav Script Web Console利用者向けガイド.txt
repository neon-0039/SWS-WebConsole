Ⅰ. SWS Web Consoleについて
--------------------------

SWS Web Consoleは、ブラウザー上で音楽を記述・再生するツールです。
作成した曲はWAV、MIDI、UST、SS形式で保存できます。
通常はアプリのHTMLファイルをブラウザーで開くだけで利用できます。

SWSでは、ソースコードに音符やテンポなどの命令を書き、コンパイルして
音楽イベントを作ります。作成したイベントをブラウザーで再生したり、
対応するファイル形式に書き出したりできます。
プログラムの書き方にはSWS、JavaScript、Pythonの3形式があります。


Ⅱ. 画面の使い方
---------------

Ⅱ-Ⅰ. ツールバーとショートカットキー
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

上部ツールバーの主な機能

  Open        .ss、.ust、.mid、.midiファイルを読み込む
  Save        現在のソースを.ssファイルとして保存する
  Compile     ソースを検査し、音楽イベントを作成する
  Play        曲を再生する。編集後は再生前にコンパイルされる
  Stop        再生を停止する
  MIDI / WAV  MIDIまたはWAV形式で書き出す
  UST         UST形式で書き出す

ショートカットはCtrl+Enter（Compile）、Ctrl+Shift+Enter（Play）、Ctrl+S（Save）、
Esc（Stop）です。

画面下部のOutputにも、WAV・MIDI・UST・SSの保存ボタンがあります。
コンパイル結果やプログラムからの表示は、右側の実行ログに表示されます。
エラーには行番号と内容が表示されます。

左側のTracks / Classesでは、トラックやクラスを選択して編集できます。
エディターの表示がコンパイル済みでも、編集後の内容が前回のコンパイル結果と
異なる場合があります。保存や書き出しの前にCompileを実行し、エラーがないことを
確認してください。

Ⅱ-Ⅱ. 設定メニュー
~~~~~~~~~~~~~~~~~~~

Settingsでは、表示言語、テーマ、エディター、音量、プラグインなどを設定できます。

・表示

  表示言語は日本語、ドイツ語、英語（米国）、英語（英国）から選べます。
  ライトモード／ダークモードボタンで画面のテーマを切り替えられます。
  言語やテーマなどの設定はブラウザーに保存され、次回も引き継がれます。

・エディター

  文字サイズ、長い行の折り返し、行番号の表示を設定できます。
  行番号の横の三角形を押すと、複数行にまたがる波括弧ブロックを折りたためます。
  折りたたんだブロックは、エディター本文をクリックすると展開されます。
  折りたたみ中も元のソースは保持され、編集・コンパイル・保存に使われます。

・下書き保存と変更の確認

  自動保存を有効にすると、未保存のソースをブラウザー内に下書き保存し、
  次回起動時に復元できます。下書きはこのブラウザー内に保存されるもので、
  .ssファイルとしてダウンロードされるものではありません。
  未保存変更の警告を有効にすると、ファイルを開くときやページを離れるときに確認します。

・音量とプラグイン

  マスター音量は再生とWAV出力に適用されます。
  Pluginボタンから内蔵音源、合成エンジン、SWSデータ／入力プラグインの画面を開けます。
  プラグイン画面を開くとSettingsは閉じます。

Ⅱ-Ⅲ. 表示と色覚サポート
~~~~~~~~~~~~~~~~~~~~~~~~

Settingsの「構文ハイライトの色」から、ソースコードの配色プリセットを選べます。
プリセットは「標準」「ソフト」「プライマリー」「ブルー」「レッド」「パープル」
「サンセット」「モノクロ」「色覚サポート」「色覚サポート（暖色系）」
「色覚サポート（高コントラスト）」です。
配色は現在のライト／ダークテーマに合わせて適用され、選択内容はブラウザーに保存されます。

色はコードの種類ごとに使い分けられます。命令、定義、数値・音名・楽器名、
表示系の命令、文字列がそれぞれ色分けされます。コメントはどのプリセットでも灰色です。
色覚サポート用プリセットは、色の組み合わせや明るさの違いを工夫した選択肢です。
見え方には個人差や画面環境による違いがあるため、必要に応じて複数のプリセットを試し、
見やすいものを選んでください。


Ⅲ. はじめての曲
---------------

次の例は、テンポを120 BPMに設定し、ピアノでC4、E4、G4を順に鳴らします。
エディターに入力し、Compileで内容を確認してからPlayを押してください。

  syntax="JS";
  tempoconst="120";
  snd("piano",4,C4)
  snd("piano",4,E4)
  snd("piano",4,G4)

C4、E4、G4の音が順番に鳴ります。
音名は文字列ではなく、C4のように記述します。
音符の長さは分母で指定します。4は4分音符、8は8分音符、16は16分音符です。
sndは音を鳴らす命令で、第1引数が楽器、第2引数が長さ、第3引数が音程です。
この例では3つの4分音符が連続して再生されます。

音量はsndのvol属性で指定できます。音量を省略すると最大音量になります。

  snd("piano",4,C4,vol=128);
  snd("piano",4,E4,vol=64);
  snd("piano",4,G4,vol=6db);

数値指定は整数の0〜128で、128が最大音量、0が無音です。
dbを付けると、最大音量からの相対的な減衰量を指定します。
vol=6dbは最大音量から6 dB下げた音量です。0db〜100dbの範囲で指定し、
小数も使えます（例: vol=3.5db）。dbの数値は減衰量なので正の値で記述します。
負の値や範囲外の値はエラーになります。
volは各sndイベントに適用され、再生とMIDI書き出しの音量に反映されます。

ピッチ点を使うには、先にpitchmodeを有効にします。

  pitchmode="on";
  snd("synth",4,C4,pitch=[Y=0,X=0;Y=10,X=240;Y=0,X=480]);

pitchの各点はY=音程変化量、X=ノート開始からのティック数で指定します。
点はセミコロンで区切り、Xは0以上の整数で昇順に記述します。
Yは10で半音、つまりY=10は1半音上、Y=-10は1半音下です。
点と点の間は直線的に補間され、最後の点以降は最後の音程を保ちます。
pitchmode="on"がない場合、ピッチ点は保持されますが内蔵再生とWAV出力には反映されません。
pitchmode="off"で無効にできます。外部出力プラグインでの再生はプラグイン側の対応が必要です。
MIDI出力にはピッチ変化を出力しません。


Ⅳ. 構文形式
-----------

ファイルの最初に構文形式を指定できます。
宣言を省略した場合はSWS形式になります。
構文宣言はソース内の最初の命令にしてください。
構文宣言には syntax="SWS"; と syntax="SoundWavScript"; のどちらも使えます。
新しいソースでは短い syntax="SWS"; 表記をおすすめします。
大文字・小文字は区別しないため、syntax="soundwavscript"; と書いても認識されます。

SWS形式

  syntax="SWS";
  snd("piano",4,C4);

通常の命令の末尾にセミコロンが必要です。
ループや条件分岐のブロックは波括弧で囲みます。

JavaScript形式

  syntax="JS";
  snd("piano",4,C4)
  console.log("計算結果:", 2 + 3 * 4)

改行で命令を区切れるため、セミコロンは省略できます。
コメントには // または /* ... */ を使います。
構文宣言には syntax="Javascript"; も使えます。

Python風形式

  syntax="py"
  snd("piano",4,C4)
  print("計算結果:", 2 + 3 * 4)

命令は1行ごとに記述し、ブロックはインデントで表します。
lp・if・elif・else・chipsの中は、半角スペース4つまたはタブ1つで字下げします。
コメントは # から行末までです。

インデントにタブとスペースが混在している場合や、全角スペースが含まれる場合は
警告が表示されます。警告のあるトラックは黄色い枠と「⚠」で示されます。
コンパイルエラーのあるトラックは赤い枠と「✕」で示されます。
3形式の記法は混ぜず、ファイル内では1つの構文形式を選んでください。
構文宣言は最初の命令として1回だけ書きます。例にある命令末尾のセミコロンは、
SWS形式では必須、JavaScript形式とPython風形式では通常省略できます。


Ⅴ. 変数と配列
-------------

Ⅴ-Ⅰ. 変数
-----------

変数の宣言方法は構文形式によって異なります。

Python風形式
  score = 10

JavaScript形式
  let score = 10
  const limit = 100

SWS形式
  number(score=10);
  const(limit=100);

Python風形式は name = 値 で変数を作成・更新します。
JavaScript形式は let で変更できる変数、constで再代入できない定数を宣言します。
SWS形式は number(name=値); で変数、const(name=値); で定数を宣言します。
値には数値・文字列・真偽値や計算式を指定できます。
宣言した値は条件式や表示式でも使えます。
変数名は英字またはアンダースコアで始め、英数字とアンダースコアを使います。
変数を使う場合は、利用する命令より前に値を設定してください。

例（JavaScript形式）

  syntax="JS";
  let score = 2
  const limit = 5
  score = score + 3
  if (score == limit) {
      console.log("score=%d", score)
  }

constで宣言した値を再代入したり、同じスコープで変数を再宣言したりすると
エラーになります。
numはlpの繰り返し回数を表す予約名です。変数名・定数名・JavaScript関数の引数に
numは使えません。

Ⅴ-Ⅱ. 配列
-----------

配列は [...] で作成します。添字は0から始まり、要素の参照と更新ができます。
添字は要素の位置を表す整数です。notes[0]は先頭、notes[1]は2番目の要素を
参照します。右辺に添字を置けば値を読み出し、代入文の左辺に置けば既存の値を
更新できます。

例（Python風形式）
  notes = [60, 64, 67]
  notes[1] = 65
  print("middle=%d", notes[1])

例（JavaScript形式）
  let notes = [60, 64, 67]
  notes[1] = 65
  console.log("middle=%d", notes[1])

例（SWS形式）
  number(notes=[60, 64, 67]);
  notes[1] = 65;
  dispin("middle=%d", notes[1]);

notes[1]は2番目の要素を指し、この例ではmiddle=65と表示されます。
配列の範囲外、小数、負の添字はエラーになります。

配列の要素を追加・削除する方法

SWS形式
  topin(value)              先頭に追加
  bottomin(value)           末尾に追加
  topshift()                先頭を削除
  bottomshift()             末尾を削除
  pointshift(index)         指定した添字の要素を削除
  pointin(index,value)      指定した位置に追加

JavaScript形式
  unshift(value)            先頭に追加
  push(value)               末尾に追加
  shift()                   先頭を削除
  pop()                     末尾を削除
  splice(index,1)           指定した添字の要素を削除
  splice(index,0,value)      指定した位置に追加

Python風形式
  insert(index,value)       指定した位置に追加
  append(value)             末尾に追加
  pop(index)                指定した添字の要素を削除
  remove(value)             指定した値を削除

使用例（配列notesに対する操作）

SWS形式
  notes.topin(55);
  notes.bottomin(72);
  notes.pointin(1,64);
  notes.pointshift(1);
  notes.topshift();
  notes.bottomshift();

JavaScript形式
  notes.unshift(55)
  notes.push(72)
  notes.splice(1,0,64)
  notes.splice(1,1)
  notes.shift()
  notes.pop()

Python風形式
  notes.insert(0,55)
  notes.append(72)
  notes.pop(1)
  notes.remove(64)

SWS形式のpointinで指定できる位置は、0から配列の要素数までです。
pointshiftには既存要素の添字を指定してください。
JavaScript形式ではpush、unshift、pop、shift、spliceが使えます。
Python風形式ではappend、insert、pop、remove、extend、clear、reverseが使えます。
配列メソッドは配列自体を変更します。SWS形式のpointinは末尾の位置
（配列の要素数と同じ位置）にも追加できます。削除対象が存在しない場合や
必要な引数が不足している場合は、コンパイルエラーになります。


Ⅵ. 音符・テンポ・キー
---------------------

Ⅵ-Ⅰ. 音符と音符長
------------------

音を鳴らす基本形

  snd("楽器名",音符の分母,音名);

例
  snd("piano",4,C4);
  snd("synth",8,G4);
  snd("piano",4+,D4);

分母の後ろに + を付けると付点音符になります。
休符は楽器名と音名に "null" または null を使います。

音符長には変数を指定できます。通常の変数は音符の分母として解釈されます。
値が4の変数なら4分音符です。

音源定義にはvoice属性があり、音源の種類を示します。プラグイン向け曲データでは、
音源定義のvoice属性が各イベントのvoiceプロパティに渡されます。
通常の楽器音源はfalse、voice属性がtrueの音源はtrueです。
音源の属性なので、sndの属性では指定しません。

  snd("piano",4,C4);
  snd("default_voice",4,C4);

上の例では、pianoイベントのvoiceはfalse、default_voiceイベントのvoiceはtrueになります。

default_voiceは内蔵の「あ」合成音源です。イベントのvoiceはtrueになり、
内蔵再生とWAV出力では、
指定された音程に合わせて基音と倍音を合成します。付属のスペクトル測定
(基本周波数約344.5Hz)から読み取った1〜18倍音の相対レベルを音色に反映します。
4倍音が最大で、高域では12〜18倍音が再び強くなる特性も含めています。
さらに3〜6kHz、4.2kHz付近をピークとする最大約-46dBのノイズ成分を加えます。
息成分は発音直後を少し強くし、音の途中では控えめにします。長い音には、
元の音声の測定を参考に約30msの立ち上がりを設け、持続部でピッチが安定していたため
ビブラートは加えません。フォルマントの時間変化などは未モデル化のため、
この音色は「あ」の試作音です。
出力プラグインを使う場合にもvoiceプロパティが渡されるため、プラグイン側で
default_voiceを個別に処理できます。

変数名の前に #: を付けると、値を音符の分母ではなくティック数として扱います。
変数名は任意です。たとえば #:number もティック指定になります。
PPQは480なので、480ティックは4分音符、240ティックは8分音符です。
この指定はsndとsleepで使えます。ティック数は正の整数にしてください。

例（JavaScript形式）
  syntax="JS";
  let noteLength = 4
  let number = 240
  snd("piano",noteLength,C4)
  snd("piano",#:number,E4)
  sleep(#:number)

従来の文字列によるティック指定 snd("piano","#480",C4) も利用できます。
通常の音符長では分母を指定し、値が大きいほど音符が短くなります。
付点音符は分母の後ろに + を付けます。ティック指定を使う場合は#:の後ろに
変数名を置き、その変数に正の整数のティック数を設定します。
たとえばPPQ=480では120ティックは0.25拍です。

Ⅵ-Ⅱ. 音源・テンポ・キー
------------------------

主な内蔵音源
  piano、grand_piano、guitar、synth、synth_lead、synth_bass、
  bass、drum、drums、kick、hihat、hi_hat、open_hihat、snare、
  sine、square、triangle、saw、sawtooth、default_voice

Plugin画面のSound欄でも音源一覧を確認できます。
指定できる音源名はSWSに組み込まれた音源です。名前のつづりを間違えると
コンパイル時にエラーになります。

テンポはBPMで指定します。tempoconstは初期テンポ、newtempoは途中からの
テンポ変更です。

  tempoconst="120";
  snd("piano",4,C4);
  newtempo="150";
  snd("piano",4,G4);

キーはkeyで指定します。キーは指定後の音に適用されます。
音名に # または b を明記した場合は、その音名が優先されます。

  key="G";
  snd("piano",4,F4);

テンポやキーは、記述した位置以降の音に反映されます。
tempoconstは曲の初期テンポを指定し、newtempoは曲の途中でテンポを変更します。


Ⅶ. 繰り返しと条件分岐
---------------------

Ⅶ-Ⅰ. 繰り返しと条件式
----------------------

SWS / JavaScript形式

  lp(4) {
      if (num == 1) {
          snd("piano",4,C4);
      } else if (num >= 2 && num <= 3) {
          snd("piano",4,E4);
      } else {
          snd("piano",4,G4);
      }
  }

Python風形式

  syntax="py"
  lp 4:
      if num == 1:
          snd("piano",4,C4)
      elif num >= 2 && num <= 3:
          snd("piano",4,E4)
      else:
          snd("piano",4,G4)

numはlpの現在の繰り返し回数です。1から始まります。

指定した回数ではなく、曲の終端まで繰り返す場合は次の形式を使います。
終端は繰り返し部分を除いた全トラックのうち、最も後ろにある拍位置です。

SWS形式

  lp:end(1) {
      snd("piano",4,C4);
  }
  snd("piano",1,G4,class="guide");

lp:endのかっこには、繰り返す間隔を拍数で指定します。ティック数で指定する場合は、
数値の前に#を付けます。1拍は480ティックです。

  lp:end(#120) {
      snd("piano",16,E4);
  }

この例では本文の処理が終わるたびに120ティック（1/4拍）待ってから次を実行します。
そのため、繰り返し開始位置の間隔は「本文の処理時間＋指定した待ち時間」です。
繰り返しは、次の開始位置が繰り返し部分を除いた曲の終端に達するまで行われます。

JavaScript形式

  function pulse() {
      snd("piano",4,C4)
  }
  setInterval(pulse, 0.5)
  snd("piano",1,G4,class="guide")

JavaScript形式のsetIntervalは、ブラウザー標準のミリ秒ではなく拍数で間隔を指定します。
第1引数には、引数のないfunctionの名前を指定します。例ではpulseの処理（1拍）が終わるたびに
0.5拍待ってから次を呼び出すため、繰り返し開始位置は1.5拍ずつ進みます。
呼び出しは、次の開始位置が繰り返し部分を除いた曲の終端に達するまで行われます。
繰り返し部分以外に拍位置を進める命令がない場合、終端が決まらないため繰り返しません。
安全のため、1つの繰り返しで実行できる回数は最大10,000回です。

条件では、比較演算子 ==、===、!=、!==、<、<=、>、>= と、
論理演算子 &&、||、! を使えます。
計算には +、-、*、/、%（余り）、**（べき乗）が使えます。
べき乗は右から評価します。たとえば 2 ** 3 ** 2 は 2 ** (3 ** 2) です。

Ⅶ-Ⅱ. 数値関数
--------------

数値関数

  関数       SWS形式       JavaScript形式       Python風形式
  ランダム   random()      Math.random()        random.random()
  切り捨て   floor(x)      Math.floor(x)        math.floor(x)
  四捨五入   round(x)      Math.round(x)        round(x)
  最大値     max(a,b,...)  Math.max(a,b,...)    max(a,b,...)
  最小値     min(a,b,...)  Math.min(a,b,...)    min(a,b,...)

randomは0以上1未満の小数を返します。乱数は式を評価するたびに生成されます。
floorとroundは数値を1つ、maxとminは数値を1つ以上指定します。
Python風形式の乱数・切り捨ては、importを書かずにrandom.random()、
math.floor()の形で使用できます。
SWS形式ではrandom()、floor()、round()、max()、min()をそのまま記述します。
JavaScriptではMath.random()など、標準のMath形式を使います。
Python風形式ではrandom.random()とmath.floor()のほか、round()、max()、min()を
使用します。これらの関数は数値式の中でも利用できます。

例（SWS形式）
  number(value=random());
  dispin(floor(value),round(value),max(2,7),min(2,7));

例（JavaScript形式）
  let value = Math.random()
  console.log(Math.floor(value),Math.round(value),Math.max(2,7),Math.min(2,7))

例（Python風形式）
  value = random.random()
  print(math.floor(value),round(value),max(2,7),min(2,7))

この例では乱数を変数valueに保存してから、同じ値に対して複数の数値関数を
適用します。乱数を別々の式で呼び出すと、そのつど異なる値になる場合があります。


Ⅷ. 表示とchips / function
-------------------------

Ⅷ-Ⅰ. 表示
-----------

文字列や計算結果を実行ログに表示できます。文字列は二重引用符で囲みます。
表示式の + はJavaScriptと同様に左から評価されます。
文字列が含まれる場合は連結、数値同士の場合は加算になります。

例（JavaScript形式）
  console.log("計算結果:"+2+3)    結果: 計算結果:23
  console.log("計算結果:"+(2+3))  結果: 計算結果:5

1つ目は文字列連結、2つ目は括弧内の数値計算が先に行われます。
SWS形式ではconsole.logをdispinに、Python風形式ではprintに置き換えます。
数値同士の計算を先に行う場合は、(2+3)のように括弧で囲んでください。

console.logとdispinは、JavaScriptのconsole.logと同じ形式指定に対応します。
たとえば、console.log("name=%s score=%d", "SWS", 12) は
name=SWS score=12 と表示されます。
%s、%d、%i、%f、%o、%O、%c、%%を使えます。
%cのスタイル指定はログ表示には適用されません。
プレースホルダーのない追加の値はスペース区切りで表示されます。
Python風形式のprintも複数の引数を表示できます。ログへの表示は音声出力には
影響せず、実行中に計算結果や条件の確認をするために使えます。

Ⅷ-Ⅱ. chipsとfunction
---------------------

同じフレーズを再利用するにはchipsを定義して呼び出します。
SWS形式とPython風形式のchipsは引数を取りません。

SWS形式
  chips riff() {
      snd("piano",8,C4);
      snd("piano",8,E4);
  }
  chips(riff);
  chips(riff);

Python風形式
  syntax="py"
  chips riff:
      snd("piano",8,C4)
      snd("piano",8,E4)
  chips(riff)

JavaScript形式ではfunctionを使い、引数を渡せます。

  syntax="JS";
  function phrase(note) {
      if (note == 1) {
          snd("piano",4,C4)
      } else {
          snd("piano",4,G4)
      }
  }
  phrase(1)

chips / functionの本体は、呼び出されたときに実行されます。
JavaScript形式のfunctionには引数を定義できます。SWSとPython風形式のchipsは
引数を受け取らず、呼び出すと定義した音符列を実行します。


Ⅸ. トラック
-----------

左側のTracks / Classesからトラックを追加・選択・名前変更できます。
追加または名前変更時に、CSS色名（tomatoなど）または16進数カラーコード
（#ff6347など）を指定できます。

音符にclass属性を付けると、そのトラックに音を割り当てられます。

  snd("piano",4,C4,class="melody");

コンパイルエラーのあるトラックは赤い枠と「✕」で示されます。
警告があるトラックは黄色い枠と「⚠」で示されます。
ソースを修正して再コンパイルすると表示が更新されます。
トラックを追加・選択して、パートごとに音符を分けて管理できます。
class属性を指定した音符は、指定した名前のトラックに割り当てられます。
トラック色にはCSS色名または#付きの16進数カラーコードを指定します。


Ⅹ. ファイルの読み込み・書き出し
--------------------------------

Ⅹ-Ⅰ. ファイルの読み込み
------------------------

Openから読み込めるファイル
  .ss       SWSソース
  .mid      MIDI
  .midi     MIDI
  .ust      UST

MIDIとUSTは音符をSWSソースに変換してエディターに表示します。
MIDIのフォーマット2は読み込めません。
読み込み後は必要に応じて編集し、Compileで内容を確認してください。

UST読み込みではPBSを開始座標、PBWを点間のティック幅、PBYを各点の高さとして
pitch=[Y=...,X=...;...]形式へ変換します。負の開始位置はX=0の高さを補間し、
小数のX座標は最も近いティックへ丸めます。PBY/PBSのセント値をSWSのY単位（10=半音）へ換算します。
PBMのカーブ種別は使用せず、ピッチ点間は直線として扱います。
pitchmode="on"のプロジェクトをUSTへ書き出すと、PBS/PBW/PBYへ変換して出力します。
pitchmodeがoffならUSTにピッチ情報を出力しません。PBMのカーブ種別は出力しません。
MIDI書き出しでもピッチ変化は出力しません。
USTの歌詞などの文字情報は読み込み時に文字コードを判定してSWSソースに取り込みます。

Ⅹ-Ⅱ. ファイルの書き出し
------------------------

書き出し形式
  SS    現在のソースを保存する
  WAV   曲を音声ファイルにする
  MIDI  音符イベントをMIDIファイルにする
  UST   歌声合成ソフト向けのファイルにする

読み込んだMIDIやUSTはSWSのソースコードへ変換されます。
変換結果は元ファイルと完全に同じ編集状態とは限らないため、エディターで確認し、
必要に応じて修正してからCompileしてください。
WAVは再生用の音声データ、MIDIは音符イベント、USTは歌声合成ソフト向けデータを
保存します。SSは編集可能なSWSソースを保存します。


Ⅺ. 合成エンジンとプラグイン
----------------------------

Plugin画面のSound欄には内蔵音源が表示されます。
Output欄では、対応するJavaScript合成エンジン（.js）を読み込み、
再生とWAV出力に使用できます。
内蔵方式に戻すには「Use built-in output」を選びます。

SWS Data Pluginの読み込み欄もあります。
プラグインは信頼できるファイルだけを読み込んでください。
合成エンジンは再生音やWAV出力の方法を切り替える機能です。
外部ファイルを読み込む場合は、提供元と内容を確認してから使用してください。

Ⅺ-Ⅰ. SWSプラグインAPI
---------------------

SWSには、曲データを受け取る「データプラグイン」、再生音を生成する
「出力プラグイン」、入力UIなどからSWSソースを編集する「入力プラグイン」があります。
いずれもJavaScriptで作成しますが、読み込み場所、呼び出され方、役割は異なります。

Ⅺ-Ⅰ-Ⅰ. データプラグイン
~~~~~~~~~~~~~~~~~~~~~~~~~

データプラグイン

  Plugin画面のSWS Data Plugins欄から .js ファイルを読み込みます。
  SWSソースに plugin("プラグイン名"); と書くと、そのプラグインが実行されます。
  プラグイン名は拡張子 .js を除いたファイル名です。
  実行時には、コンパイル済みの曲データが引数 SWS として渡されます。

SWSの主なデータ構造

  SWS.api_version    APIバージョン。現在は 1
  SWS.sws_version    曲データのSWSバージョン情報（現在の値は "0.2"）
  SWS.type           データの種類。"song"
  SWS.project        曲全体の情報
  SWS.events         音符や休符などのイベント配列

  SWS.project.tempo      最初のテンポ（BPM）
  SWS.project.key        曲のキー
  SWS.project.tempo_map  テンポ変更を含むテンポ情報

各イベントには、type（noteまたはrest）、instrument、start、duration、
notes、class、track_id、volume、lyric、voice、line、source_positionなどが含まれます。
voiceは音源定義から渡される真偽値で、通常の楽器音源ではfalse、default_voiceではtrueです。
このプロパティはSWSデータプラグインと出力プラグインの両方に渡されます。
startとdurationは拍単位です。notesは音符の配列で、各音符にはpitch、midi、
key、lyricなどが含まれます。volumeは線形音量で、0〜100の範囲です。
SWSソースのvol=0〜128はこの値に換算され、最大音量が100になります。
曲のproject.pitch_modeはpitchmodeのon/off状態、イベントのpitchはpitch点の
points配列です。pitch点はpitchmodeがonのとき内蔵再生とWAV出力に反映されます。
外部出力プラグインにはpitch_modeとpointsが渡されますが、再生への適用はプラグイン側の対応が必要です。
MIDI出力では無視されます。UST読み込みはPBS/PBW/PBYをpitch点へ変換し、UST書き出しは
pitchmodeがonの場合にPBS/PBW/PBYへ変換します。PBMは扱いません。

APIバージョンを確認してからデータを使う例

  if (SWS.api_version !== 1) {
      throw new Error("Unsupported SWS API");
  }
  console.log(SWS.project.tempo);
  console.log(SWS.events.length);

SWSソースから呼び出す例

  plugin("myPlugin");

上の例では、myPlugin.jsを読み込んでおく必要があります。プラグインには
曲データのコピーが渡されます。プラグイン内でデータを書き換えても、
エディターの曲データ自体は変更されません。

Ⅺ-Ⅰ-Ⅱ. 出力プラグイン
~~~~~~~~~~~~~~~~~~~~~~~~

出力プラグイン

  Plugin画面のOutput欄から .js ファイルを読み込みます。
  ファイルは render(song, sampleRate) 関数を持つオブジェクトを返します。
  songにはデータプラグインと同じ形式の曲データが渡され、sampleRateは
  1秒あたりの音声サンプル数です。song.sample_rateにもサンプルレートが入ります。

renderは、左右の音声データを次の形で返してください。

  return {
      left: new Float32Array(...),
      right: new Float32Array(...)
  };

leftとrightは空でないFloat32Arrayで、要素数を同じにします。各要素は有限の
音声サンプル値である必要があります。返された音声は再生とWAV出力に使われます。

Ⅺ-Ⅰ-Ⅲ. 入力プラグイン
~~~~~~~~~~~~~~~~~~~~~~~~

入力プラグインは、ピアノロールなどの入力画面からSWSコードを作成・編集するための
プラグインです。Plugin画面のInput欄でJavaScriptファイル（.js）を読み込み、
一覧からプラグインを開きます。プラグインの画面から「プラグイン一覧に戻る」を選ぶと
閉じられます。読み込んだプラグインは現在のページを開いている間だけ有効です。
ページを再読み込みした後は、もう一度ファイルを読み込んでください。

入力プラグインのファイルは、読み込まれるときにプラグイン定義オブジェクトを返します。
mount(container, editor)が呼び出され、containerに入力UIを作り、editor APIから
エディターのソースを読み書きします。次の例はボタンを押すと、選択位置に音符コードを
挿入する最小の入力プラグインです。

  return {
      name: "音符入力サンプル",
      mount(container, editor) {
          const button = document.createElement("button");
          button.textContent = "ピアノのC4を挿入";
          button.addEventListener("click", () => {
              editor.insertText('snd("piano",4,C4);\n');
          });
          container.appendChild(button);
      }
  };

editor APIの主な機能

  getText()                         現在エディターに表示中のソースを取得
  getSelection()                    選択範囲の開始位置・終了位置・文字列を取得
  insertText(text)                  選択範囲を置き換えてコードを挿入
  replaceSelection(text)            選択範囲を指定文字列で置き換え
  replaceRange(start, end, text)    指定範囲を置き換え
  replaceAll(text)                  エディター内のソース全体を置き換え
  setSelection(start, end)          エディターの選択範囲を設定

ソース編集は通常のエディター入力として反映されるため、変更状態の更新や下書き保存の対象になり、
Ctrl+Zで取り消せます。入力プラグインは現在選択中のトラックのエディター内容を操作します。
start/endはソース先頭からの文字位置で、0から数えます。

入力プラグイン、データプラグイン、出力プラグインはいずれもブラウザー内でJavaScriptを実行します。
エディター本体のDOMはAPIから直接渡しませんが、入力プラグイン自体を隔離するものではありません。
信頼できるファイルだけを読み込み、提供元と内容を確認してください。



Ⅻ. 困ったときは
---------------

音が出ない
  Compileを押し、エラー表示がないか確認してください。

SWS形式のエラー
  命令末尾のセミコロンと、波括弧の対応を確認してください。

Python風形式のエラー
  ブロックの字下げ幅と全角スペースの混入を確認してください。
  インデントは4スペース単位です。

変数が未定義というエラー
  条件式や表示式で使う変数名、関数の引数を確認してください。

MIDI / USTを書き出せない
  曲をCompileしてから、もう一度書き出してください。

音符の長さが想定と違う
  分母を確認してください。ティック数として指定する場合は、変数名の前に#:
  を付け、変数の値が正の整数になっていることを確認してください。

配列操作でエラーになる
  添字が配列の範囲内か、SWS形式のpointinの位置が0から要素数までかを
  確認してください。メソッド名と引数の数も構文形式に合わせてください。

表示や数値関数でエラーになる
  選択中の構文形式に合った関数名を使用しているか確認してください。
  例: SWS形式はfloor(x)、JavaScriptはMath.floor(x)、Python風はmath.floor(x)。

エラーの行番号とメッセージは、右側のコンソールとエラー欄に表示されます。
表示された行番号の周辺を確認し、ソースを修正してから再度Compileしてください。
